§ 01연구 현장의 고민

분석 기법보다 먼저,
연구 질문과 방어 가능한 근거가 필요합니다

ChatGPT, 분석 툴, 파이썬까지 시도해 보고 오시는 연구자가 많습니다. 막히는 지점은 대부분 비슷합니다.

데이터는 있는데 어떤 분석을 해야 할지 모르겠습니다.
기법부터 고르지 않습니다. "정책 발표 전후 언론 프레임은 어떻게 달라졌나"처럼 데이터로 확인할 질문을 먼저 정의하고, 그 질문에 맞는 방법을 설계합니다.
LLM으로 분류했는데 결과를 믿어도 되는지 모르겠습니다.
분류 기준(Codebook)을 정하고 표본을 사람이 직접 검증합니다. 프롬프트와 모델 버전을 고정해 기록하므로 같은 조건으로 다시 돌려 확인할 수 있습니다.
워드클라우드 몇 장으로는 보고서가 되지 않습니다.
빈도에서 끝내지 않고 토픽·시계열·네트워크·집단 비교를 연결합니다. 결과는 보고서 문장으로 옮길 수 있게 해석과 함께 드립니다.
심사 의견이나 자문회의에서 방법론 질문이 나옵니다.
전처리 규칙, 사용자 사전, 토픽 수 선정 근거(Coherence 등), 주요 설정값을 문서로 남겨 방법론 기술과 질의 대응에 쓰실 수 있게 합니다.

같은 "텍스트마이닝"이라도 데이터 특성에 따라 단계 구성이 달라집니다. 위는 실제 프로젝트에서 설계했던 파이프라인 예시입니다. SCI 논문에 쓰인 DF·DoV·DoD·증가율 계열 Rank 지표, LDA+TF-IDF·LDA+감성분석 같은 혼합 기법, KNU·VADER 등 감성사전과 맞춤 사전 구축도 지원합니다.

최신 방법이 항상 더 낫다고 보지 않습니다. 같은 데이터에 전통 기법과 LLM 기법을 함께 적용해 비교하고, 연구 목적에 더 맞는 결과를 근거와 함께 제안합니다.

§ 04신뢰성 · 재현성

AI가 만든 결과를
그대로 넘기지 않습니다

생성형 AI를 썼다는 것만으로 결과를 믿을 수는 없습니다. LLM 분석에는 아래 검증 절차를 적용합니다.

분류 기준 정의연구진과 Codebook·라벨 정의 합의
표본 수작업 검증무작위 표본을 사람이 직접 라벨링
프롬프트·모델 고정버전과 설정값을 기록해 재현 가능하게
전체 데이터 분석고정된 조건으로 일괄 처리
오류 검토불일치 사례 확인, 모델 간 결과 비교
신뢰도 보고일치도 지표와 한계를 함께 기술

재현성을 위해 남기는 기록

  • 데이터 출처, 수집 기간과 조건
  • 전처리 규칙, 불용어·사용자 사전
  • 토픽 수 선정 근거와 주요 하이퍼파라미터
  • 프롬프트 버전, 사용 모델과 실행 일자
  • 원자료와 분석 결과를 잇는 문서 ID 매핑

기관 데이터 보안

  • 개인정보가 포함된 자료는 비식별 처리 방식을 먼저 협의
  • 외부 API 반출이 어려우면 로컬 LLM으로 처리하는 방식 검토
  • 공개 웹 데이터는 이용약관·robots.txt·관련 법령 범위에서 수집
  • 보안 서약 등 기관 절차는 착수 전에 맞춰 진행

§ 12자주 묻는 질문

의뢰 전에 많이 묻는 것들

분석 방법이 아직 정해지지 않았는데 상담할 수 있나요?

네. "이 연구 질문을 데이터로 확인하려면 어떤 분석을 해야 하나요?"부터 함께 검토합니다. 연구 목적과 보유 데이터를 알려 주시면 가능한 분석 설계를 제안드립니다.

데이터가 없어도 의뢰할 수 있나요?

수집 가능성부터 검토합니다. 뉴스, 커뮤니티, 회의록, 논문 초록 등 공개 데이터는 사이트 이용약관, robots.txt, 관련 법령을 확인한 범위에서 수집 방법을 협의합니다.

내부 자료라 외부로 반출하기 어렵습니다.

개인정보는 비식별 처리 방식을 먼저 협의합니다. 외부 AI API로 보내기 어려운 자료는 로컬 LLM으로 처리하는 방식을 검토할 수 있습니다. 보안 서약 등 기관 절차가 있으면 착수 전에 알려 주세요.

논문이나 보고서를 대신 써 주나요?

아니요. 본 서비스는 데이터 분석과 분석 컨설팅입니다. 결과 해석, 표·그림, 방법론 기술 문서는 드리지만 논문과 보고서 작성은 연구자가 직접 하시는 것을 전제로 합니다.

비용과 기간은 어떻게 정해지나요?

데이터 규모, 분석 난이도, 기한에 따라 달라집니다. 상담에서 범위를 확인한 뒤 산출물, 일정, 비용을 함께 제안드립니다.

세금계산서나 기관 결제가 필요합니다.

크몽 안전결제로 진행하시면 크몽 발행 세금계산서를 받으실 수 있습니다. 기관 직접 계약이 필요하면 메일로 기관의 계약 절차를 알려 주세요.

분석 과정을 연구실에서 직접 재현하고 싶습니다.

정제 데이터, 분석 코드, 설정값 문서를 함께 드리며, 과정을 이해할 수 있도록 실습 동영상 자료도 제공합니다. 연구실 단위 교육이 필요하면 맞춤 교육으로도 진행합니다.
